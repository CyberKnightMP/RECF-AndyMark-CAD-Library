This parts library features every legal AndyMark part that is currently available. This library is meant to make the CAD setup process easier so you don't have to look through the parts list and manualy organize them. 

All files originate from: https://andymark.com/collections/robits

This repo is purely for the purpose of a generic AndyMark robits library. For VEX-based CADs, use one of the following:

**Fusion 360:** [VEX-CAD-Fusion-360-Library](https://github.com/VEX-CAD/VEX-CAD-Fusion-360-Library)

**Onshape:** [Onshape VEX V5 Parts Guide](https://www.onshape.com/en/blog/vex-iq-vex-v5-parts-libraries)

**Inventor:** [VEX-CAD-Inventor](https://github.com/VEX-CAD/VEX-CAD-Inventor)

## Installation
1. Download the latest release of the zip file
1. Unzip the downloaded file
### For Fusion
3. Install [GitHubToFusion360](https://marketplace.autodesk.com/apps/27c6b84a-45bf-47e9-9213-b5474d9e81be) from the Autodesk App Store
4. In Fusion press `Shift+S` → run **GitHubToFusion360**
5. Paste: `__` → Install
6. Run **FusionBatchImport** (`Shift+S`) and select the unzipped folder. Takes ~5 minutes.
7. Successfuly imported parts
